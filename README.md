# 项目超简介
***本项目目前处于开发测试阶段，功能尚待完善，请测试者根据自己的情况使用***

## 支持&不支持：
- 支持.xlsx和.csv格式的账单表单导入
- 支持收支来源对账户账本的映射
- 支持时段检索和关键词检索查询相关账单
- 支持手动记账
---
- 暂不支持除微信、支付宝、银行卡之外的官方账单表单导入（不想做:P）
- 不支持实时采集支付信息（不能做:( ）
- 无icon

## 使用
你得先去支付平台上把账单下载下来，最好存个显眼的位置，然后在配置页“新增来源”里选择平台导入账单，等它解析完表里的信息你就能看到自己的收支情况了。理论上它是能正确解析所有账单的属性的，如果有错帐漏帐你可以手动“记一笔”。还有就是汇总页饼图的数据是根据关键词计算的，某些数据无法百分比保真，建议自定义类别。
